# Changes 2026-09-03

## iOS exercise transition freeze fixed

**Issue:** On iOS, moving between exercise questions showed a white screen for 2-3 seconds.

**Root cause:** In LessonSessionScreen's `submitAnswer()`, both `setExercise(next)` and `setSubmitting(false)` were called inside `advanceFn()`, causing React to batch them into one commit. On iOS (especially emulator/slower devices), mounting the new exercise component took 2-3 seconds. During this time, the spinner overlay (rendered when `submitting && !feedback`) blocked the entire view with a white background.

**Fix:** Call `setSubmitting(false)` immediately after `advanceFn()` is invoked, rather than inside it. This clears the spinner before the new exercise mounts, allowing the user to see content rendering sooner. The `submitLockRef` stays inside `advanceFn()` as the real submit-prevention mechanism.

**Impact:** Exercises now transition smoothly without the white-screen stall. The submit lock still prevents double-taps.
