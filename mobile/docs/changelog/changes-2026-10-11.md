# Changes, 2026-10-11

## Progress screen: Open, Completed, Closed (same states as Search)

User, after build 20044: "in progress if surah not opened it should stay
under closed, then open then complete". The "In Progress" section was built
from `fetchAllSurahProgress`'s `in_progress` state, which also covers a surah
whose first level was started but never finished. Search already calls that
surah closed (open = first level complete), so the two screens disagreed.

Asked before building: which surahs go under Closed, and the section order.
User chose **every surah that isn't open** (including never-touched ones)
and the order **Open, Completed, Closed**.

`src/screens/home/SurahProgressScreen.tsx`:
- Open: `in_progress` with `completed > 0` (levels unlock in order, so that
  means the first level is done), plus `unavailable` (only ever produced by
  the detailed fetch, which only runs once the first level is complete).
  Sorted by percent, as before.
- Completed: unchanged.
- Closed: everything else, in surah order (1 to 114). Rows mirror Search's
  closed card: plain card, `LESSON AYAH 1-N`, `JUMP HERE ▶`, and tapping
  opens the same `StartSurahModal` "Open {surah}?" confirm before jumping to
  the map. No progress bar or chest, since nothing has been earned yet.
- "In Progress" renamed "Open" to match Search's wording.
