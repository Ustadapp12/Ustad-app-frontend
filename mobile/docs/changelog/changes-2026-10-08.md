# Changes — 2026-10-08

## Search Surah screen redesigned to match the new Figma mock

User pointed at the Figma file (`Landing Page`, node `1111:7418` — later
clarified to mean the Search screen, not the Progress screen it looked like
at first) and asked for `SearchSurahsScreen.tsx` to be rebuilt to match it,
using real surah data instead of the mock's repeated placeholder "Al-Baqara"
cards.

`src/screens/home/SearchSurahsScreen.tsx`:

- **Header** retitled "Surahs" → "Search Surah" to match the design.
- **Search bar** placeholder changed to "Search by Surah name or number".
  The mock's placeholder also mentions "Juzz number", but `SurahListing`
  (`src/data/allSurahs.ts`) carries no `juz` field for surahs 1–77 — only
  `juz30Surahs.ts` has one, and only for 78–114 — so a Juz search can't be
  built honestly across all 114 yet. Left out rather than wired to a search
  that would silently fail for most of the catalogue.
- **New Map button** next to the search bar (🗺️, matching the emoji already
  used for the Map tab in `MainTabs.tsx`), navigates to
  `MainTabs`/`Map` with no params.
- **Row redesign**: replaced the old Open/Done/Closed tag+legend system with
  the mock's two card states —
  - a surah with real fetched progress (first level completed) gets the
    green card: solid badge, a progress bar filled to the real
    completed/total fraction, and a reward icon
  - everything else gets the plain card with a "JUMP HERE ▶" CTA instead of
    a progress bar
  - the progress fraction is never estimated — it's only shown for surahs
    the existing second-pass fetch (`learningApi.levels`) already has real
    level data for; everyone else just shows no bar, consistent with the
    existing "never fabricate progress" rule
- **Reward icon** on an in-progress card now opens `LumoInfoModal` (the
  existing "Coming soon!" component already used elsewhere, e.g.
  `ProfileScreen.tsx`) — nothing real is behind it yet, by explicit
  instruction.
- **Removed**: the sort button (Order/Size/Status popover) and the
  Open/Done/Closed legend row, neither of which appear in the new design.
  This is a real feature removal, not just a restyle — flagged to the user
  rather than silently dropped.

`LESSON AYAH 1-{ayah_count}` uses the surah's real total ayah count
(`ayah_count` already in `ALL_SURAHS`), matching the mock's "1-7" / "1-286"
pattern exactly rather than inventing per-lesson ranges that don't exist in
the data.
