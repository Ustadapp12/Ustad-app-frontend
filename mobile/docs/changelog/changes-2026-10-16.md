# Changes, 2026-10-16

## The new map becomes Home, for TestFlight 1.0.40

User's call (asked 2026-10-16, "Replace Home with it"): the Figma day map
(`src/screens/home/map2`, built 2026-10-15) is now the Map tab in every build,
not a dev-only preview. `MapScreen.tsx` itself is untouched but no longer used
by the tabs, so the old map is not in this build.

- `MainTabs.tsx`: Map tab = `Map2Screen`. New `Building` tab (the 8-point
  star) between Quests and Leaderboard, which shows the "Building your
  exercises" page. The old tab bar (emoji icons, labels) is replaced by
  `Map2TabBar`, the Figma bar with the selected tab's icon in green. On Home
  it draws nothing, because the map renders its own translucent bar over the
  scrolling map. Elsewhere it is the solid bar, laid out so screens end above
  it. The dev "M2" button is gone; the dev "V2" button stays.
- `Map2BottomBar`: every tab now has a selected state (grey art turned
  `#218565`, the same swap as Figma's green chest; Home has its own drawn
  selected art).
- `Map2Screen` as the Map tab:
  - It takes the tab's navigation, and its bar opens the real tabs.
  - Pressing Home from another tab brings you back to your level.
  - `jumpToSurah` / `jumpToGroupId` / `jumpToLevelIdx` params from Search
    Surahs and Surah Progress are honoured, then cleared.
- `RootNavigator.tsx`: `ComingSoon` (the Journey / Review page) is registered
  in release builds too. The dev-only `Map2` route is removed.
- `comingSoon/`: the page body was split into `BuildingContent` (shared),
  `ComingSoonScreen` (pushed from Journey / Review: back arrow plus its own
  bar with the chest selected, as in Figma 1151:9846) and `BuildingTabScreen`
  (the star tab).
- Version 1.0.39 -> 1.0.40 (`package.json`, synced to `app.json` and the iOS
  `MARKETING_VERSION`).
- Release notes 1.0.40 drafted in `src/data/releaseNotes.ts`, awaiting the
  user's approval.

Known gaps in this build:
- The guided tour is never offered, because only the old map offered it.
- The map has no pull-to-refresh. It still refreshes on app foreground and
  after a lesson.
- Hearts and gems show a dash until the backend has them.

Pre-flight: `tsc` clean, eslint 0 errors, jest 56/56,
`npx expo export:embed --eager --platform ios --dev false` bundles (1,394
modules, 6.9MB), with all 7 map2 PNGs and Lumo in the copied assets.
