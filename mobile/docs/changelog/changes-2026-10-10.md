# Changes, 2026-10-10

## Exercise layout never creates scrolling

User, while the 1.0.36 build was being prepared: "dont create scroll though".
In yesterday's `ExerciseLayout`, the space reserved above the feedback sheet
was a fixed bottom padding, so on a short phone content that fitted on its
own could become scrollable purely because of that reserved space.

`src/components/lesson/ExerciseLayout.tsx` now measures the viewport and the
content block and only reserves space that is actually free:
`paddingBottom = max(14, min(wanted, viewport - content - 14))`. Content that
fits never scrolls; on a short phone it just sits a little lower. Only
content genuinely taller than the screen scrolls, as before this layout
existed. `alwaysBounceVertical={false}` so a screen that fits does not
rubber-band on iOS. `contentStyle` now goes on the measured inner wrapper
(AyahDisplay's `alignItems: 'center'` still applies, with full-width cards).
