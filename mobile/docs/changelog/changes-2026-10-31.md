# Changes 2026-10-31

## Code cleanup from the 30 Oct audit

Acts on [`docs/code-audit-2026-10-30.md`](../code-audit-2026-10-30.md). No screen changes on purpose;
two behaviour fixes are called out below. `src/` went from 304 files / 29,739 lines to
299 files / 28,421 lines.

Verified after every step and at the end: `tsc --noEmit` clean, no unused locals
(`noUnusedLocals`/`noUnusedParameters`), jest 98/98, and a production JS bundle builds for both
Android and iOS (`react-native bundle --dev false`). Not yet run on a device.

### Speak exercises merged

`ReadAndSpeak` and `ReadAyahAndSpeak` shared about 65% of their code. Now:
`exercises/speak/useSpeakAttempt.ts` (record → score → one retry), `speak/SpeakExerciseShell.tsx`
(Ustad bubble, mic area, Skip, error, retry sheet), `speak/styles.ts`. Each exercise keeps only its
own content (word chips + Hear / ayah card + Hear the Ayah), its result fields, its Crashlytics tag
and its scoring text, all exactly as before.

- **Bug fix:** the 60 s auto-stop timer called a stale copy of the tap handler that still saw
  `speakState === 'idle'`, so at 60 s it tried to start a second recording instead of stopping and
  submitting. It now calls the latest handler through a ref.
- ReadAyahAndSpeak's mic now has the same plain wrapper View as ReadAndSpeak (tour measuring); no
  size or position change.

### Hook dependencies (32 lint errors → 0)

- Stable values (`useRef(...).current` animations, store actions, memoized callbacks, route params)
  added to their dependency arrays: no behaviour change.
- `LessonSessionScreen.handleBack` is now a `useCallback`; the hardware-back effect depends on it.
- `useStreakFrozenPopup` depends on the streak-state string itself, not the whole `learning` object.
- `ExerciseSlide` calls `onSettled` through a ref, so a new callback from a parent re-render can't
  fire it twice.
- Deliberately run-once effects keep their keys, with an `eslint-disable-next-line` and the reason:
  useMapData's startup fetch, Splash's auto-navigate, the lesson's skip-unhandled and seed-first-
  exercise effects, and the per-exercise resets in AudioFill/AyatThenOrder/ReorderOrSequence/
  SequenceExercise (`tiles` is rebuilt each render, so listing it would wipe placed tiles after
  every tap).

### Inline styles (161 → 0)

Every `style={{ ... }}` moved into the file's existing sheet (`<Screen>.styles.ts`, a local
`StyleSheet`, or the `sc()` factory). Components with no sheet got a local one at the bottom. Values
computed at render time (`left: x * s`, animated transforms, accent colours) stay inline next to the
named style: `[styles.hill, { left: -41 * s, top: topInset }]`. Shared names across screens:
`mascotBox`, `mascotImgFlush`, `mascotShadow`; the exercises' `locked && { opacity: 0.7 }` is now one
`EX.locked`. Conditional literals became conditional styles (TourOverlay `hidden`, Map2BottomBar
`insetFillSolid`/`insetFillMap`, Map2NodeView `nodeBoxFetching`/`nodeBoxRaised`). Map2Screen's
`CellRenderer` uses a module-level `cellStyles.raised` so it keeps one identity for the list's life.
